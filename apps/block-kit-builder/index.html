DoU Block Kit Builder

A tool for building a Block Kit message to send to a DoU channel. When a structured message — an error report or a deployment notice — needs a title, a divider, and a field table instead of one plain-text blob, the sender builds this payload and sends it.

The screen has three panes.

  • Compose — start from a template or stack blocks one at a time, and reorder them by dragging.
  • Message — rendered with the same renderer as a real DoU message. That's why the preview never drifts from the real thing.
  • Payload — the JSON those blocks compile to. Edit and copy it in either direction.

Four blocks are supported — header (title) · section (a paragraph and two-column fields) · divider (a dividing line) · context (a small gray line). Text uses Slack mrkdwn syntax: *bold*, _italic_, `code`, <url|label>. Any other block still renders without breaking — its raw JSON is shown in place, along with its label.

You can start from three templates: Error · Attendance · Deployment.
